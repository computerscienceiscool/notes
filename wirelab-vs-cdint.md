## Top 10 highest-risk outdated assumptions

1. **A signer/key/local role is the durable agent identity.** CD Int separates AgentID, key, process, machine, and repository commit; its identity method remains open.
2. **A pCID identifies the code that executed an event.** It identifies protocol semantics; audit/replay needs separately identified executable and dependency closure.
3. **A generic CID link carries parent/ownership/retention semantics.** Generic scanning yields structural edges only; selected pCIDs supply semantic labels.
4. **A runtime root CID proves recoverability or authorizes adoption.** It names bytes; local adoption, signer/policy checks, host-capability review, and closure availability/retention evidence are separate.
5. **“Replay” can safely rerun an old external action.** Historical verification, pure recomputation, and side-effect reconciliation are different operations.
6. **An external write is established by sending an action or storing an action hash.** CD Int’s refinement needs source key/snapshot, approval, request/response, readback, retry, and correction evidence.
7. **A storage receipt makes the storage agent repository authority.** The owner publishes its repository; the storage agent publishes its own retain/serve evidence.
8. **Continuous sync implies safe convergence of authority.** It does not resolve split brain, exclusive-writer handoff, or partitioned shared resources; fencing/lease/quorum/capability remains open.
9. **Every message must have a stand-alone signature.** CD Int treats individual, aggregate, and hybrid authentication as pCID-specific alternatives still requiring measurement/decision.
10. **A capability token, manifest, or discovered implementation CID grants ambient authority.** Each resource controller must locally approve/redeem bounded authority; parsing and discovery do not authorize effects.

6. Which closure-availability and retention promises must gate runtime-root adoption, correction, and claimed restoreability?

8. Should the speculative congruence/convergence bridge ever become a normative requirement, or remain research framing pending a TE and evidence?

## Bottom line

Wire Lab’s later POC18–POC21 direction is substantially aligned with the
available CD Int design: pCID-defined semantics, local acceptance, parent-linked
evidence, no global truth, CAS event sources, rebuildable views, local adoption,
and corrective rather than erasing history. The main gap is not a wholesale
model reversal. It is a production-hardening refinement around durable identity,
separating semantic pCIDs from exact execution closure, treating generic CID
links as structural only, making storage/availability evidence explicit, and
making external effects/readback/reconciliation first-class. Several exact
schemas remain open; the report intentionally does not turn them into decisions.
